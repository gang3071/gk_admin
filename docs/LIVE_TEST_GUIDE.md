**登录：** https://console.cloud.tencent.com/live

**步骤：**
```

2. 找到直播流：mojiangjuan
3. 点击「播放地址」
```

**地址格式：**

---

**规则：**
```

rtmp://tencent2.kkcnw.cn/live/mojiangjuan?txSecret=xxx&txTime=xxx
```

**注意：** 保留鉴权参数（txSecret和txTime）

### 5️⃣ 常见测试场景

#### 场景1：直播流未推送

**测试：** 填写正确的HLS地址，但主播未开播

**预期：**
- 显示「连接中...」
- 3秒后提示「连接时间较长，请稍候...」
- 最终显示连接失败错误

---

#### 场景2：地址过期

**测试：** 使用txTime已过期的地址

**预期：**
- 播放失败
- 显示鉴权错误（403或类似）
- 提示更新直播地址

---

#### 场景3：网络中断

**测试：** 播放过程中断网

**预期：**
- 播放暂停
- 状态变为「缓冲中...」
- 网络恢复后自动继续（或需要刷新）

---

#### 场景4：切换直播地址

**测试：**
```
1. 填写RTMP地址 → 预览（可能失败）
2. 关闭Modal
3. 更新为HLS地址 → 预览（应该成功）
```

**预期：**
- 每次打开Modal都重新加载播放器（destroyOnClose）
- 不会残留上次的播放状态

### 6️⃣ 浏览器兼容性测试

#### Chrome/Edge（推荐）
- ✅ HLS: 需要hls.js（已集成TCPlayer）
- ✅ FLV: 支持
- ❌ RTMP: 不支持

#### Firefox
- ✅ HLS: 需要hls.js
- ✅ FLV: 支持
- ❌ RTMP: 不支持

#### Safari (Mac/iOS)
- ✅ HLS: 原生支持（最佳）
- ⚠️ FLV: 需要插件
- ❌ RTMP: 不支持

#### 移动端浏览器
- ✅ HLS: 广泛支持
- ⚠️ FLV: 部分支持
- ❌ RTMP: 完全不支持

**测试建议：** 优先使用Chrome测试，确保HLS格式正常工作。

### 9️⃣ 问题排查流程

#### 播放器不显示
```
1. 检查是否有控制台错误
2. 确认live-player.html文件存在
3. 检查iframe src是否正确编码
4. 查看Network请求是否被拦截
```

#### 黑屏无画面
```
1. 确认直播流是否正在推送
   - 使用VLC播放器测试地址
   - 或访问 http://xxx.com/live/xxx.m3u8
2. 检查txTime是否过期
3. 检查txSecret是否正确
4. 尝试刷新页面
```

#### 音频正常但无视频
```
1. 检查视频编码格式（H.264推荐）
2. 检查分辨率是否过大
3. 尝试降低码率
```

#### 延迟过高
```
1. HLS延迟通常10-30秒，属于正常
2. 如需低延迟，使用FLV格式
3. 或联系腾讯云开通快直播（1秒内）
```
