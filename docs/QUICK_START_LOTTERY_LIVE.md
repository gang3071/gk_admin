# 🚀 摸奖券直播快速开始指南

## 🎯 一键生成直播地址功能

现在你可以在后台管理界面**一键生成**摸奖券直播地址，无需手动复制粘贴或计算防盗链参数！

---

## ✨ 功能特点

### 1. 完全可视化操作
- ✅ 下拉选择腾讯云配置
- ✅ 输入流名称（如：mojiangjuan）
- ✅ 设置有效天数（默认30天）
- ✅ 一键生成4种协议地址

### 2. 智能推荐
- ✅ 默认选中FLV格式（低延迟，性价比高）
- ✅ 显示过期时间
- ✅ 自动填充到输入框

### 3. 便捷操作
- ✅ 一键复制推流地址（配置OBS）
- ✅ 切换协议地址
- ✅ 手动输入备选

---

## 📋 使用步骤（3步完成）

### 步骤1：打开直播地址设置

```
后台管理 → 摸奖券活动列表 → 更多操作 → 添加直播地址
```

**弹窗界面：**

```
┌─────────────────────────────────────────┐
│  💡 提示：可以使用腾讯云配置一键生成直播地址  │
└─────────────────────────────────────────┘

快速生成：
┌───────────────────────┬──────────────┐
│ [选择腾讯云配置 ▼]    │ [一键生成]   │
└───────────────────────┴──────────────┘

流名称：
┌─────────────────────────────────────────┐
│ 流名称：mojiangjuan                      │
└─────────────────────────────────────────┘

有效期：
┌─────────────────────────────────────────┐
│ 有效期：[30] 天                         │
└─────────────────────────────────────────┘

────────── 或手动输入 ──────────

直播地址：
┌─────────────────────────────────────────┐
│                                         │
│  http://tencent2.kkcnw.cn/live/...     │
│                                         │
└─────────────────────────────────────────┘
```

---

### 步骤2：生成直播地址

#### 2.1 选择腾讯云配置

点击"**选择腾讯云配置**"下拉框：

```
┌─────────────────────────────────┐
│ 摸奖券直播配置 (tencent2.kkcnw.cn)
│ 配置 #1 (domain1.example.com)
│ 配置 #2 (domain2.example.com)
└─────────────────────────────────┘
```

**说明：** 自动加载 `machine_tencent_play` 表中的配置

---

#### 2.2 填写流名称（重要！⭐）

```
流名称：mojiangjuan
```

**流名称规则：**
- ✅ 只能包含英文、数字、下划线
- ✅ 建议使用有意义的名称
- ✅ 必须与OBS推流配置一致

**推荐命名：**
```
mojiangjuan             // 通用名称
lottery_123             // 活动ID
lottery_spring_2026     // 活动名称+年份
lottery_20260617        // 日期
```

---

#### 2.3 设置有效期（可选）

```
有效期：[30] 天
```

**说明：**
- 默认30天
- 范围：1-365天
- 到期后需要重新生成

---

#### 2.4 点击"一键生成"按钮

**等待1-2秒，生成成功后显示：**

```
┌─────────────────────────────────────────┐
│ ✅ 生成成功！请选择合适的协议：          │
└─────────────────────────────────────────┘

○ FLV   低延迟（2-5秒）⭐ 推荐后台使用
○ HLS   高兼容（10-30秒）- 推荐移动端
○ WebRTC 超低延迟（<1秒）- 费用较高

┌─────────────────────────────────────────┐
│ 过期时间：2026-07-17 12:00:00           │
├─────────────────────────────────────────┤
│ 推流地址（OBS）：                        │
│ rtmp://tencent2.kkcnw.cn/live/mojian... │
│                                    [复制]│
└─────────────────────────────────────────┘

直播地址：
┌─────────────────────────────────────────┐
│ http://tencent2.kkcnw.cn/live/          │
│ mojiangjuan.flv?txSecret=xxx&txTime=xxx │
└─────────────────────────────────────────┘
```

---

### 步骤3：选择协议并保存

#### 3.1 选择推荐协议

**选项A：FLV（推荐）⭐⭐⭐⭐⭐**
```
✅ 延迟：2-5秒
✅ 费用：标准（0.26元/GB）
✅ 适用：后台预览、PC网页
```

**选项B：HLS**
```
✅ 延迟：10-30秒
✅ 费用：标准（0.26元/GB）
✅ 适用：移动端H5、iOS
```

**选项C：WebRTC**
```
✅ 延迟：<1秒（超低）
⚠️ 费用：约2倍（0.52元/GB）
✅ 适用：实时互动、竞技直播
```

---

#### 3.2 点击"确定"保存

直播地址自动保存到活动配置中！

## 🎬 OBS推流配置

### 步骤1：复制推流地址

在生成结果中，点击"**推流地址（OBS）**"旁的**复制按钮**：

```
复制的地址：
rtmp://tencent2.kkcnw.cn/live/mojiangjuan?txSecret=xxx&txTime=xxx
```

---

### 步骤2：配置OBS

**打开OBS Studio → 设置 → 流：**

```
服务：自定义
服务器：rtmp://tencent2.kkcnw.cn/live/
串流密钥：mojiangjuan?txSecret=xxx&txTime=xxx
```

**分解说明：**
```
完整地址：
rtmp://tencent2.kkcnw.cn/live/mojiangjuan?txSecret=xxx&txTime=xxx

拆分为：
服务器：rtmp://tencent2.kkcnw.cn/live/
       └── 域名 + /live/

串流密钥：mojiangjuan?txSecret=xxx&txTime=xxx
         └── 流名称 + 鉴权参数
```

---

### 步骤3：推荐参数

**视频设置：**
```
分辨率：1280×720 (720p) 或 1920×1080 (1080p)
帧率：25 fps 或 30 fps
视频码率：2000-4000 Kbps
```

**音频设置：**
```
音频码率：128 Kbps
采样率：44.1 kHz 或 48 kHz
```

**输出设置：**
```
关键帧间隔：2秒（降低延迟）
编码器：x264 或硬件编码（NVENC/AMD等）
```

---

### 步骤4：开始推流

1. 点击OBS的"**开始推流**"按钮
2. 等待3-5秒连接
3. 检查OBS底部状态栏：
   - ✅ 绿色表示推流正常
   - ❌ 红色表示连接失败

2. 網絡連接問題
3. 直播地址已過期

```

---

### 步骤3：检查画面

**正常情况：**
- ✅ 画面流畅播放
- ✅ 音频清晰
- ✅ 延迟2-5秒（FLV）或10-30秒（HLS）
- ✅ 状态指示灯显示绿色

**异常情况：**
- ❌ 黑屏 → 检查OBS是否推流
- ❌ 卡顿 → 降低OBS码率

## 💡 常见问题

### Q1：一键生成按钮灰色不可点击

**原因：** 未选择腾讯云配置

**解决：**
```
1. 点击"选择腾讯云配置"下拉框
2. 选择任意一个配置
3. 按钮变为可点击状态
```

---

### Q2：生成失败提示"腾讯云配置不存在"

**原因：** `machine_tencent_play` 表中无数据

**解决：**
```
1. 进入：后台管理 → 机台管理 → 腾讯云播放配置
2. 添加配置：
   - 标题：摸奖券直播配置
   - 拉流域名：tencent2.kkcnw.cn
   - 拉流KEY：你的腾讯云密钥
3. 保存后重试
```

---

### Q3：播放失败显示"直播流未推送"

**原因：** OBS未开始推流或推流地址错误

**解决：**
```
1. 检查OBS状态栏是否显示"直播"（绿色）
2. 检查OBS串流密钥是否包含txSecret和txTime
3. 尝试停止推流后重新开始
```

---

### Q4：地址过期怎么办？

**检查过期时间：**
```
生成结果中显示：
过期时间：2026-07-17 12:00:00
```

**如果已过期：**
```
1. 重新点击"添加直播地址"
2. 重新点击"一键生成"
3. 使用新生成的地址
```

---

### Q5：想要更低延迟怎么办？

**方案1：使用WebRTC（推荐）⭐**
```
1. 生成地址后选择"WebRTC"选项
2. 延迟 < 1秒
3. 费用约为FLV的2倍
```

**方案2：优化OBS参数**
```
1. 设置关键帧间隔 = 2秒
2. 降低码率到2000 Kbps
3. 使用有线网络推流
```

---

### Q6：多个活动可以共用同一个直播地址吗？

**可以，但不推荐！**

**推荐做法：**
```
每个活动使用独立的流名称：
- 活动1：lottery_123
- 活动2：lottery_456
- 活动3：lottery_789
```

**共用风险：**
- 所有活动显示相同的直播内容
- 无法区分不同活动的观看数据
- OBS推流到一个地址，所有活动都显示

## 📊 协议对比表

| 协议 | 延迟 | 费用 | 兼容性 | 推荐场景 |
|------|------|------|--------|---------|
| **FLV** | 2-5秒 | 标准 | 良好 | ⭐⭐⭐⭐⭐ 后台预览 |
| **HLS** | 10-30秒 | 标准 | 最好 | ⭐⭐⭐⭐ 移动端H5 |
| **WebRTC** | <1秒 | 约2倍 | 良好 | ⭐⭐⭐⭐⭐ 实时互动 |
| **RTMP** | - | - | 不支持 | ❌ 仅推流用 |

## 🎯 最佳实践

**推荐配置：**
```

有效期：30天
OBS码率：2000-3000 Kbps

- 延迟低（2-5秒），满足管理员实时监控

- 移动端兼容性最好
- iOS原生支持
- 费用标准

协议：WebRTC

**原因：**
- 延迟 < 1秒，几乎实时
