========================================
摸奖券功能 - 快速部署指令
========================================

【步骤1】执行数据库迁移
-----------------------------------------
cd D:\gk_api
php vendor/bin/phinx migrate


【步骤2】重启 gk_admin 服务
-----------------------------------------
cd D:\gk_admin
php windows.php stop
php windows.php start


【步骤3】配置权限（后台操作）
-----------------------------------------
1. 登录后台 → 角色管理
2. 编辑"渠道管理员"角色
3. 勾选以下权限：
   ✅ 摸奖券管理
     ✅ 进行中的活动 (index, form-post, form-put, index-delete, closeActivity, prizeConfig, savePrizeConfig)
     ✅ 历史活动记录 (historyList)
     ✅ 中奖记录 (index, grantPrize, exportRecords)
4. 保存


【步骤4】启用功能（后台操作或SQL）
-----------------------------------------
后台操作：
  渠道管理 → 编辑渠道 → 摸奖券功能 = 启用

SQL方式：
  UPDATE yjb_channel SET lottery_ticket_enabled = 1 WHERE id = {渠道ID};


【步骤5】验证
-----------------------------------------
1. 使用渠道管理员账号登录
2. 左侧菜单应显示"摸奖券管理"
3. 测试创建活动
4. 测试配置奖品


========================================
故障排查
========================================

【问题】菜单不显示
→ 检查: lottery_ticket_enabled 是否为 1
→ 检查: 角色是否有菜单权限
→ 清除浏览器缓存

【问题】数据库字段不存在
→ 确认迁移已执行: php vendor/bin/phinx status
→ 查看表: SHOW CREATE TABLE lottery_ticket_activity;

【问题】权限拒绝
→ 重启服务: php start.php restart
→ 清除Redis缓存: redis-cli DEL ADMIN_PERMISSIONS_*
