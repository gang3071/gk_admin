## 📡 推送频道设计

### 5.1 频道命名规范

```
玩家个人频道：player_{player_id}
渠道广播频道：department_{department_id}
活动频道：activity_{activity_id}
全局频道：global
```

### 5.2 频道订阅规则

**客户端订阅：**
```javascript
// 玩家登录后订阅
ws.subscribe('player_' + playerId);          // 个人通知
ws.subscribe('department_' + departmentId);  // 渠道公告
ws.subscribe('activity_' + activityId);      // 活动更新
```

**后台订阅：**
```javascript
// 管理员登录后订阅
ws.subscribe('admin_' + adminId);            // 个人通知
ws.subscribe('department_' + departmentId);  // 渠道数据
ws.subscribe('activity_' + activityId);      // 活动监控
```

## 🎨 UI/UX 设计要点

### 6.1 状态颜色规范

```
🔵 蓝色 - 未开始 (STATUS_NOT_STARTED)
🟣 紫色 - 预热期 (STATUS_PREHEATING)
🟢 绿色 - 打码中/进行中 (STATUS_BETTING/STATUS_ONGOING)
🟡 黄色 - 开奖中 (STATUS_DRAWING)
🟠 橙色 - 已结束 (STATUS_ENDED)
🔴 红色 - 已关闭 (STATUS_CLOSED)
```

### 6.2 数据刷新策略

```
实时数据（WebSocket推送）：
- 打码进度
- 发券通知
- 活动状态变更
- 中奖通知

定时刷新（轮询）：
- 统计数据：每30秒
- 参与人数：每1分钟
- 中奖记录：每2分钟

手动刷新：
- 所有列表数据
- 详情页数据
```

1. **加载优化**

2. **操作反馈**
   - Toast提示

3. **数据导出**

## 📊 数据指标定义

### 7.1 核心KPI

```
参与率 = 参与玩家数 / 总玩家数 × 100%
发券率 = 已发券数 / 参与玩家数
券使用率 = 已使用券数 / 已发券数 × 100%
中奖率 = 中奖人数 / 参与人数 × 100%
打码完成率 = 达标人数 / 参与人数 × 100%
```

### 7.2 运营数据

```
日均打码量 = 累计打码量 / 活动天数
日均发券数 = 总发券数 / 活动天数
人均打码量 = 累计打码量 / 参与人数
人均发券数 = 总发券数 / 参与人数
ROI = 总奖金池 / 累计打码量 × 100%
```

## 🔧 技术实现要点

### 8.1 API接口清单

```
GET  /api/lottery/dashboard           - 仪表板数据
GET  /api/lottery/activity/:id/stats  - 活动统计
GET  /api/lottery/activity/:id/players- 参与玩家
GET  /api/lottery/activity/:id/tickets- 券号明细
GET  /api/lottery/activity/:id/progress- 打码进度
GET  /api/lottery/activity/:id/winners - 中奖记录
POST /api/lottery/activity/:id/draw    - 执行开奖
POST /api/lottery/activity/:id/live    - 直播控制
GET  /api/lottery/realtime/bet-ranking - 打码排行
GET  /api/lottery/realtime/recent-tickets- 最近发券
```

### 8.2 WebSocket事件

```
客户端 -> 服务端：
- subscribe_activity     - 订阅活动
- unsubscribe_activity   - 取消订阅
- heartbeat              - 心跳

服务端 -> 客户端：
- bet_progress_update    - 打码进度更新
- ticket_issued          - 发券通知
- activity_status_change - 状态变更
- lottery_win            - 中奖通知
- live_started           - 直播开始
- live_ended             - 直播结束
- draw_result            - 开奖结果
```

### 8.3 数据缓存策略

```
Redis缓存：
- 活动基本信息：1小时
- 统计数据：5分钟
- 参与人数：1分钟
- 打码排行：30秒

实时数据（不缓存）：
- 打码进度
- 发券记录
- 中奖记录
```
